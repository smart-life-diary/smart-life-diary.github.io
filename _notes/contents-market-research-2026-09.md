# コンテンツマーケットの需要調査（2026-09-10）

次のコンテンツ出品を決めるために、ココナラ コンテンツマーケットを実測した。
測定スクリプトは `_notes/portfolio-tools/contents_demand.py`。

---

## 1. 測り方

コンテンツマーケットは `/contents_market` 配下の Next.js アプリで、一覧は
**JavaScriptで描画される。** curl では中身が取れない。しかもこの環境からは
Chromium で coconala.com を開けない（プロキシが `ERR_CONNECTION_RESET` を返す。
crowdworks.jp と同じ）。

そこで、**ページが叩いている GraphQL を直接呼んだ。**

```
POST https://apiprxy.coconala.com/graphql
query contentsMarketSearchPublicContents(filter: {categoryIds, keyword, limit, page, sortBy})
  → contents{title price favoriteCount kind category} paginationInfo{totalCount}
```

エンドポイントとクエリ名は、`/contents_market/_next/static/chunks/*.js` を
落として grep すると出てくる。

**需要の代理指標はお気に入り数（★）。** サービス出品と違い、コンテンツ出品には
販売件数が公開されていない。APIにもその項目が無い。無料で押せるぶん販売より
軽い指標だが、「見て、欲しいと思った人の数」は拾える。
供給は `totalCount`。

## 4. 読み取れたこと

**① 需要は「ココナラで稼ぐ方法」に集中している。**
売上の伸ばし方（★145）と出品戦略（★70）が突出。2位カテゴリの5〜10倍。
コンテンツを買っているのは、主にココナラの出品者。

**② テンプレートの棚は死んでいる。**
プレゼンテーションは出品104に対して★最大3。ドキュメントは1,035あって★最大14、
しかもその中身は占い鑑定書テンプレ。パワポ・Excelのテンプレを足しても伸びない。

**③ 既存のコンテンツ出品（工事別原価管理表 2,000円）が★0なのは構造どおり。**
出来の問題ではなく、棚が悪い。テンプレート＞その他は1,742出品ある。

**④ 建設に寄せる手はここでも無い。** 8月の読み違えと同じ結論。

**⑤ 唯一、こちらの持ち物と重なるシグナルが2つある。**
- 学び＞ビジネススキル講座の1位が「**Excelスキル診断チェックシート 500円 ★11**」。
  出品174と薄く、**50項目で自己診断させる形**が効いている
- AI＞作業自動化・効率化の2位が「**生成AIを活用した資料作成術 3,000円 ★13**」

## 6. 出すもの

**提案書・営業資料の「通らない理由」診断（500円・即納）**

- カテゴリ：学び ＞ ビジネススキル講座
- 形式：スマホで動くHTML1ファイル ＋ 印刷用PDF
- 中身：45項目・3軸（構成／情報／表現）で点数化し、落ちている軸ごとに直し方を出す

根拠は3つ。

1. **同じ棚の1位が同じ形**（Excelスキル診断チェックシート 500円 ★11）。出品174と薄い
2. **診断エンジンは在庫**。ポートフォリオに動くデモが5本ある。作り直さなくていい
3. **診断項目そのものが、公共案件の技術提案書15年の中身。** 他の出品者には項目が書けない

500円・即納は、初受注（出品F 3,000円・即納）と同じ形。**評価を早く積むならこの形。**

2本目は、1本目の反応を見てから
「AIに資料の構成を作らせる指示文」を AI＞作業自動化・効率化 に出す。
先に2本並べない。
