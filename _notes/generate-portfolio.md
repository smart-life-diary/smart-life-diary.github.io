# ポートフォリオ画像の生成手順

ココナラのポートフォリオは**画像のみ**登録できます（動画・GIF不可）。
そのため、デモを実際に自動操作してスクリーンショットを撮り、
操作の流れを4カット横並びに合成した画像を作ります。

生成物は `portfolio/` に出力されます。

## 必要なもの

- Chromium（`/opt/pw-browsers/chromium-1194/chrome-linux/chrome`）
- `pip install playwright pillow`
- 日本語フォント（`/usr/share/fonts/truetype/fonts-japanese-gothic.ttf` / IPAGothic）

環境が変わってパスが違う場合は、各スクリプト冒頭の `CHROME` と `FONT` を書き換えてください。

## 実行

```bash
cd _notes/portfolio-tools
python3 shots.py     # デモ5本を自動操作して shots/ に撮影（20枚）
python3 compose.py   # 4カットを合成して portfolio/ に出力（10枚）
python3 cover.py     # プロフィールのカバー画像（portfolio/cover.png）
```

## 何をしているか

**`shots.py`** — 390×844（スマホ相当）／2倍解像度で各デモを開き、以下を撮ります。

| カット | 内容 | 取得方法 |
|---|---|---|
| ① start | スタート画面 | 読み込み直後 |
| ② question | 設問1問目 | スタートボタンを押した直後 |
| ③ result | 結果画面の上部 | 全問に回答したあと最上部へスクロール |
| ④ share | シェア導線のクローズアップ | `.share-hint` `.copy-btn` `.again` `.cta` `.promptbox` の外接矩形 |

セレクタは5本のデモで構造が違うため、クラス名を横断的に拾う作りにしています。
新しいデモを足したら `DEMOS` に slug を追加してください。既存のクラス命名
（`.opts` / `.options` / `.result` など）に合わせておけば、そのまま動きます。

**`compose.py`** — 各カットの下端の単色余白を削り、幅430pxに揃えて横並びに合成します。
ヘッダーに作品名・構成・訴求文を載せ、カット間に矢印を描きます。
作品名や「○問→○タイプ」の文言は `DEMOS` に定義しています。

## 出力

| ファイル | 用途 |
|---|---|
| `portfolio/<slug>-flow.png` | 4カット合成。ポートフォリオのメイン画像 |
| `portfolio/<slug>-result.png` | 結果画面の単体。2枚目以降に追加する |
| `portfolio/cover.png` | プロフィールのカバー画像（2000×500） |

slug: `isekai` / `side-biz` / `ai-level` / `shachiku` / `golf`

## 注意

`shots.py` は各設問で**常に最初の選択肢**を選びます。そのため結果は毎回同じ
タイプになります（例：隠れ社畜度チェックは100%）。別のタイプを見せたい場合は
`window.__opts[0]` の添字を変えてください。

## 販売用テンプレートについて

`templates/` に、ココナラで販売する診断ツールのテンプレート4点があります。

| ファイル | 内容 |
|---|---|
| `type-a-4types.html` | タイプ判定型（加点式・サブタイプ表示） |
| `type-b-score.html` | スコア％表示型（カウントアップ＋バー） |
| `type-c-multi.html` | 多分岐型（評価軸×親和度・レーダーチャート） |
| `はじめにお読みください.html` | 購入者向けの使い方ガイド |

**このディレクトリは `.gitignore` に入れてあります。** リポジトリが public のため、
コミットすると販売中の商品が誰でもダウンロードできる状態になります。

3点とも編集箇所を `▼ ここから編集してください` / `▲ 編集はここまでです` の
2行で挟んであり、その内側だけで設問・結果・配色が完結します。
共通仕様は、1ファイル完結・スマホ最適化・X/LINEシェア・「前の質問にもどる」対応。

## Instagram リール（`reels.py`）

```bash
cd _notes/portfolio-tools
python3 reels.py     # reels/ に mp4 3本（1080×1920）
```

デモをヘッドレスChromiumで操作しながら録画し、ffmpeg でテロップを焼き込みます。

- **画質**：ページ全体に `zoom` をかけて等倍で録画します。小さく録って拡大すると
  劣化するため、拡大処理を通しません。
- **構図**：1080×1420 で録り、上に300pxの帯を足して 9:16 にします。テロップは
  その帯の中に置くので、本文と重なりません。
- **Instagramの安全領域**：下端はキャプションとUIで隠れるため、下部には文字を
  置いていません。
- **音声**：無音のAACトラックを付けています（互換性のため）。音楽はアプリ側で。

Playwright 同梱の ffmpeg は VP8/WebM しか出力できず Instagram に上げられません。
`apt-get install ffmpeg`（libx264・drawtext入り）が必要です。

テロップの文言は `REELS` に定義しています。**回答は選択肢を巡回して選ぶため、
結果は実行ごとに変わります。** テロップに具体的な点数やタイプ名を書かないでください。
