## 0. 前提：「今日の収益化」の定義

正直に線を引いておきます。

| | 可否 | 理由 |
|---|---|---|
| 今日、出品を公開する | ○ | 実質、文章とサムネイルを用意するだけ |
| 今日、受注（購入）が入る | ○ | ただし**公開依頼への提案**を打つ場合に限る |
| 今日、現金が口座に入る | × | 売上金は振込申請とスケジュールに従うため即日化は不可 |

**出品しただけでは売れません。** 公開直後の出品は検索順位が最下層で、放置すると数週間ゼロが続きます。
初日に受注を取る唯一の現実的な経路は「**公開依頼（リクエスト）一覧から、こちらから提案を送る**」です。
今日の作業時間の半分はこれに充ててください。

**今日のゴール：出品3本を公開 + プロフィール整備 + 提案10件送信。**

## 5. ポートフォリオ登録（5点／今日中）

**【実地確認済み】ポートフォリオに登録できるのは画像のみです。**
動画・GIFは受け付けられませんでした。当初「録画を登録する」方針で書いていましたが、
実際に試したところ不可だったため、以下の方針に差し替えます。

**登録方法の注意**：取引成立前の外部URLのやり取りは規約上リスクがあるため、
GitHub PagesのURLを説明欄に直貼りするのは避けてください。

**画像で「動き」を伝える方法（4カット構成）— 作成済み**

1枚の画像に操作の流れを4カット横並びで合成します。動画が使えなくても、
「回答したら結果が出る」という体験の流れは静止画の連番で十分に伝わります。

```
 ① スタート  ▶  ② 設問に答える  ▶  ③ 結果が出る  ▶  ④ シェア／導線
```

`portfolio/` に生成済みです。そのままココナラにアップロードできます。

| ファイル | 用途 | サイズ |
|---|---|---|
| `portfolio/<slug>-flow.png` | 4カット合成（ポートフォリオのメイン画像） | 2100×1750 |
| `portfolio/<slug>-result.png` | 結果画面の単体（2枚目以降に追加） | 1560×1300 |

**両方とも1.20:1（6:5）です。** ココナラの画像表示枠をプレビューから実測したところ
約1.20:1でした。4:3で作ると片側4.8%が切り落とされ、作品名の1文字目と4カット目の
右端が失われます。比率を合わせたうえで、左右に7%の余白を確保しています。

4カットを横に並べると枠に対して縦が余るため、下端に「この診断でできること」を
3点入れて埋めています。

slug は `isekai` / `side-biz` / `ai-level` / `shachiku` / `golf` の5種類。

- スマホ幅390pxの実機相当でレンダリングし、Retina解像度（2倍）で撮影
- 各カットは実際にデモを自動操作して撮ったもの。モックアップではない
- ヘッダーに「作品名／構成（○問→○タイプ）／スマートフォン最適化・HTML1ファイルで納品」を明記済み
- 再生成する場合は `_notes/generate-portfolio.md` の手順を参照

### 初受注から分かったこと（2026-09-09）

公開から約2週間で、**最初に売れたのは3,000円・即納の在庫商品**だった。
24,000円の診断制作（8/6公開）と6,000円の受注生産（8/22公開）は動いていない。

評価0の出品者から買う判断には、次の3つが効いたと考えられる。

| | |
|---|---|
| 価格 | カテゴリの最低価格。失っても痛くない額 |
| 即納 | 待たされない。相手の作業に依存しない |
| 完成品 | 打ち合わせが不要。買う前に何が届くか確定している |

**受注生産は、評価が付いてから動き始める。** 順番が逆だった。
以後、新しい領域に出るときは「最低価格・即納・在庫」の1本を先に置く。

購入者は「建設業は未経験」と書いてきた。帳票の名前も中身も知らない相手に
ファイルを5点渡すだけでは、開いて終わる。納品メッセージには
**最初に試す1手**（日報に1行入れると集計が動く）を必ず入れること。
