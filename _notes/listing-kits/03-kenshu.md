## 3. サービス内容

**サービス内容（635／1000）**
```
社内研修、顧客向けセミナー、勉強会。「知っていることを全部入れたら、聞く側が持ち帰れなかった」という資料を、聞いた人が翌日から動ける順番に組み立てます。

▼ 研修資料でよくあること
・話し手が知っている順に並んでいて、聞き手が必要とする順になっていない
・情報が多すぎて、何を覚えて帰ればいいか分からない
・「なぜそれをやるのか」が無く、手順だけが並んでいる

▼ 作り方
1. 受講者は誰で、研修のあと何ができるようになってほしいかをお聞きします
2. 構成案（何を、どの順番で、何枚で）をお出しし、ご確認いただきます
3. ご承認後、スライドを作成します
4. ご要望を2回まで反映します

▼ 基本料金に含まれるもの
・構成案の作成
・スライド10枚までの作成（PowerPoint .pptx、編集できる状態でお渡し）
・修正2回

▼ 経験について
建設コンサルタントとして15年、公共案件の技術提案書を書いてきました。専門用語の多い内容を、専門外の相手に伝わる形へ置き換える作業が中心です。研修資料も同じで、「知っている人の順番」を「初めて聞く人の順番」に組み直すことが本体だと考えています。

▼ 対応できる資料
新人研修・業務研修の資料、顧客向けセミナー資料、勉強会の資料、手順を教えるマニュアル形式の資料。

▼ 原稿がなくても作れます
箇条書きのメモ、既存の資料、話した内容の書き起こし。どの形でも構いません。「受講者に何をできるようになってほしいか」さえあれば、順番と言葉はこちらで組み立てます。
```

## 12. トークルーム回答例（購入者側・出品者側のペア、タイトル欄は無い）

**1 購入者側（71／300）**
```
新入社員向けに、うちの業務の流れを説明する研修をすることになりました。60分です。手元には、業務マニュアル（Word、30ページ）があります。
```
**1 出品者側（168／300）**
```
ありがとうございます。60分であれば、スライドは20〜25枚が目安です。10枚を超える分は「スライド5枚追加」を2〜3つ追加していただく形になります。マニュアル30ページをそのまま並べると「全部入り」になってしまうので、先に「研修のあと、新入社員に何ができるようになってほしいか」を3つまでに絞っていただき、それを軸に構成案を作ります。
```

**2 購入者側（48／300）**
```
取引先向けの製品セミナーです。技術部門が作った資料があるのですが、専門的すぎて営業が使えません。
```
**2 出品者側（127／300）**
```
拝見します。技術部門の資料は、たいてい「製品の仕組み」の順に並んでいます。取引先向けには「相手の困りごと→それがどう変わるか→仕組み→導入の手順」の順に組み替えると、営業の方が話しやすくなります。技術資料は材料としてお預かりし、構成案を先にお出しします。
```

**3 購入者側（22／300）**

```
**3 出品者側（122／300）**
```
